# make-up :lipstick:

Adding some glitter to the terminal 💖

## Summary

What's this repo for?

- Learn how to use the [Lipgloss]() library and create [Bubbletea](https://github.com/charmbracelet/bubbletea) application with it.
- Apply some of the concepts learned to other languages:
  - C++: Build a set of components like [Bubbles](https://github.com/charmbracelet/bubbles) and [Lipgloss](https://github.com/charmbracelet/lipgloss) on top of [NotCurses](https://github.com/dankamongmen/notcurses)
  - C: Same.
  - Rust: Explore the same idea in Rust (I don't know exactly how yet).

That's it.

Good luck!
